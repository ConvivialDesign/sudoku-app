How to Play Sudoku

Sudoku is a number-placement puzzle based on logic. Your goal is to complete the grid so that every row, every column and every 3×3 box contains the numbers 1 to 9 exactly once.

The basic rules of Sudoku

A standard Sudoku puzzle contains a 9×9 grid divided into nine smaller 3×3 boxes. Some numbers are already provided when the puzzle begins.

To solve the puzzle:

  1. Each row must contain the numbers 1 to 9.
  2. Each column must contain the numbers 1 to 9.
  3. Each 3×3 box must contain the numbers 1 to 9.
  4. No number may appear twice in the same row, column or box.

How to begin solving

Start by looking for rows, columns or boxes that already contain many numbers. These areas are usually easier to complete because fewer possibilities remain.

  1. Choose a row, column or 3×3 box.
  2. Identify which numbers are missing.
  3. Check where each missing number can legally be placed.
  4. Fill in a number when only one position is possible.
  5. Repeat the process across the puzzle.

Use elimination, not guessing

Sudoku should be solved through deduction. Before placing a number, check the row, column and box connected to that square.

When every other possibility has been eliminated, the remaining number is the correct answer.

Beginner tips

  • Look for nearly completed rows, columns and boxes first.
  • Scan the whole puzzle instead of focusing on one difficult square.
  • Use pencil notes when several possibilities remain.
  • Do not rush into guessing.
  • Recheck the grid after every successful placement.
